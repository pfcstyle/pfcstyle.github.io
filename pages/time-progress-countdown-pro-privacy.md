# Time Progress Countdown Pro Privacy Policy

_Last updated: 2026-06-17_

## Summary

Time Progress Countdown Pro is designed as a local-first, buy-once iOS app.
The app does not require account creation and does not use a remote server for core product behavior.

## Data the app stores

The app stores data created by the user on the device, including:

- countdown / count-up events
- event dates, titles, colors, and direction settings
- optional reminder selection for an event
- local widget snapshot data used to show event and Year Progress information in widgets

## Notifications

If you enable notifications, the app can schedule optional local reminders for individual events.
These reminders are generated on-device.

## Data sharing

The app does not sell personal data.
The app does not require account login.
The app does not include a remote backend for syncing your event data.
The app does not include third-party analytics or advertising SDKs in the current product scope.

To support widgets, some app data is shared locally between the main app and the widget extension through Apple's App Group container on the same device.

## Network services

The current app scope does not depend on a remote service for the core countdown, Year Progress, widget, or reminder experience.

## Your choices

You can:

- choose whether to grant notification permission
- edit or delete your events inside the app
- remove the app from your device if you no longer want to use it

Because the app is local-first, removing local app data or uninstalling the app may remove the stored event data on that device.

If this privacy policy changes materially, the updated version will be posted at the same URL.
